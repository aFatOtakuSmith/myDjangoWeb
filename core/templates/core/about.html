自我介绍

你好，我是莫晓。一名热衷于创造与折腾的开发者，游走在 嵌入式硬件 与 Web 全栈 的交界处。

目前，我将绝大多数精力投入到了个人的开源全栈项目 myDjangoWeb 的开发中。我喜欢将底层的传感器数据通过 MQTT 汇聚到云端，再用优雅的代码将它们展示在精美的网页上。在业余时间，我也组乐队、写博客，用代码记录生活。

主导项目

myDjangoWeb 个人全栈数字中枢

全栈开发 · 独立主导
  • 基于 Django 5.2 构建的高度集成化模块系统，涵盖博客、作品、待办习惯管理及沉浸式音乐播放等子系统。
  • 设计并实现了 “前端直连读取 + 后端代理写入” 的混合物联网安全通信模型，利用 MQTT 与 WebSocket 实现硬件数据毫秒级推流及安全控制。
  • 前端采用原生 HTML/CSS/JS 深度定制，实现了基于 ColorThief 的动态 UI 主题色渐变、歌词多端同步交互等极致的视觉与交互体验。
  • 编写 Watchdog 自动化守护脚本，配合 Systemd 实现服务器后台任务的秒级监听、崩溃自启与自动化运维。
